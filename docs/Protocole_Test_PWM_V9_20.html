14.1 — Câblage OPA541 + JDS6600 (amplificateur transitoires)

⚠️ ATTENTION — Haute tension possible (40V+)

Le montage OPA541 peut générer des tensions élevées. Respecter les précautions.

14.3 — Cold-crank dynamique (RD6006P seul)

🥶 Simulation démarrage moteur avec chute/remontée rapide

Test sans OPA541 — Directement avec RD6006P.

Profil Cold-Crank

Séquence temporelle :
T0 : 12V stable (régime normal)
T1 : 12V → 6V en ~100ms (démarreur engagé)
T2 : 6V maintenu pendant 2s (démarrage moteur)
T3 : 6V → 14,4V en ~500ms (alternateur charge)
T4 : 14,4V stable (régime charge)

📟 FNIRSI 1014D — Configuration

ParamètreRéglage

CH2+5V_MCU
V/div5V/div (les deux)
Timebase500ms/div
TriggerCH1, Falling, 10V
ModeNormal (pas Single)

Procédure manuelle

  1. RD6006P : 12V / 500mA → Output ON
  2. Vérifier circuit fonctionne (pot ~5V → OUT_PROT ≈ 10,5V)
  3. Armer oscillo
  4. Tourner rapidement le bouton tension RD6006P : 12V → 6V
  5. Maintenir 6V pendant 2 secondes
  6. Tourner rapidement : 6V → 14,4V
  7. Capturer la trace (screenshot oscillo)

Procédure avec logiciel PC (recommandée)

💻 RidenPowerSupply.exe — Séquence programmée

  1. Connecter RD6006P au PC via USB
  2. Lancer RidenPowerSupply.exe
  3. Sélectionner port COM, baud rate, cliquer CONNECT
  4. Dans l'interface, régler les valeurs manuellement ou utiliser les presets
  5. Cliquer bouton "AP" pour activer l'enregistrement courbes
  6. Exécuter la séquence (manuellement ou via script)
  7. Les données V/I sont enregistrées
  8. Cliquer "AP" à nouveau pour exporter vers Excel

Export FNIRSI 1014D (oscilloscope)

📟 FNIRSI 1014D — Screenshots et Waveforms

FonctionBoutonRésultat
Screenshot écranBouton capture (📷)Image PNG sauvée en interne
Sauver waveformBouton waveformDonnées brutes sauvées

Procédure export vers PC

  1. Connecter FNIRSI 1014D au PC via câble USB
  2. L'oscilloscope apparaît comme un disque amovible (U-disk)
  3. Pas besoin de driver ni de logiciel spécial
  4. Ouvrir le disque dans l'explorateur Windows
  5. Copier les fichiers :
    • SCREENSHOT/ → Images PNG
    • WAVEFORM/ → Données brutes
  6. Renommer les fichiers avec date/test (ex: 14_2_LoadDump_CH1.png)
Tip : Après chaque test important, appuyer sur le bouton screenshot IMMÉDIATEMENT pour capturer la trace.

Export RIDEN RD6006P (alimentation)

🔋 RD6006P — Courbes V/I vers Excel

LogicielRidenPowerSupply.exe
Prérequis.NET Framework 4.7.2
ConnexionUSB (port COM)
ExportFichier Excel (.xlsx)
Durée max24 heures d'enregistrement

Procédure complète

  1. Installation (une seule fois) :
    • Télécharger le logiciel depuis le site RIDEN ou CD fourni
    • Dézipper dans un dossier (ex: D:\RidenPowerSupply\)
    • Si demandé, installer Net Framework4.7.2.exe
    • Lancer RidenPowerSupply.exe
  2. Connexion :
    • Connecter RD6006P au PC via USB
    • Attendre installation driver (automatique)
    • Dans le logiciel : sélectionner port COM correct
    • Baud rate : 115200 (par défaut)
    • Slave address : 001 (par défaut)
    • Cliquer "CONNECT"
  3. Enregistrement :
    • Cliquer sur le bouton "AP" (en haut à droite)
    • L'enregistrement démarre (courbe V/I en temps réel)
    • Exécuter les tests (rampes, coupures, etc.)
    • Cliquer à nouveau sur "AP" pour arrêter
  4. Export :
    • À l'arrêt, le logiciel propose d'exporter
    • Choisir "Export to Excel"
    • Sélectionner emplacement et nom de fichier
    • Ouvrir le fichier Excel généré

Créer un graphique dans Excel

  1. Sélectionner colonnes A (temps) et B (tension)
  2. Insertion → Graphique → Courbe (XY)
  3. Ajouter série C (courant) sur axe secondaire si besoin
  4. Titrer le graphique (ex: "Cold-Crank Dynamique V1.15")
  5. Exporter en image si nécessaire
