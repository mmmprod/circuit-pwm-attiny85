🆕 V9.18 — Topologie sortie V1.15 (3 couches protection)
Chaîne de sortie V1.15 :
Q1 Drain → R13 (10Ω) → OUT_DRAIN → D4 (1N5822) → OUT_PROT → D5 (TVS) + C11 → J3

Points de mesure :
• OUT_DRAIN = avant D4 (tension source = 12V - Vds - V_R13)
• OUT_PROT = après D4 (tension jauge = OUT_DRAIN - Vf_D4)
🛑 RÈGLE ABSOLUE : PWM_IN ne doit JAMAIS flotter en l'air !
Une entrée haute impédance en l'air capte du bruit → comportement erratique.
Toujours connecté au potentiomètre OU au générateur JDS6600.
