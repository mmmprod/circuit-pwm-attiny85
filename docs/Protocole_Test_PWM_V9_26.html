📐 Note technique — Comportement ratiométrique ADC

Pourquoi les seuils restent stables malgré les fluctuations de +5V_MCU ?

Le circuit utilise un comportement ratiométrique :

  • Le potentiomètre est alimenté par +12V_PROT (~11,7V)
  • L'ADC de l'ATtiny85 utilise VCC (+5V_MCU) comme référence
  • Le diviseur R1/R2 ramène la tension PWM dans la plage ADC

🛡️ Code V1.7.9: Si ADC <50 ou >950 → Force OFF
📌 V9.24 — Deux méthodes de test

Le but est de simuler une panne du diviseur R1/R2 (fil coupé, soudure froide).

Méthode A — Test entrée flottante (original)

  1. État initial : Pot à ~5V → OUT_PROT allumé (~10,5V)
  2. Action : Retirer physiquement le fil JAUNE (curseur pot → PWM_IN)
  3. Résultat : PWM_IN se retrouve "en l'air" (flottant)
  4. Observation : OUT_PROT doit passer de ~10,5V à 0V en <2s
  5. Après test : Rebrancher le fil jaune
🆕 V9.24 — Méthode B — Test déterministe (plus reproductible)

Si le test flottant donne des résultats variables, utiliser cette méthode :

  1. État initial : Pot à ~5V → OUT_PROT allumé (~10,5V)
  2. Action : Déconnecter le fil JAUNE du pot et le court-circuiter vers GND
  3. Résultat : PWM_IN = 0V → ADC ≈ 0 (sous seuil ADC_MIN_VALID = 50)
  4. Observation : OUT_PROT doit passer à 0V en <2s (fail-safe)

Phase 6.1 — Test fail-safe ADC limite haute V9.24 CORRIGÉE

🛡️ Validation ADC_MAX_VALID = 950

Le code V1.7.9 force OFF si ADC > 950. Ce test vérifie cette protection.

⚠️ POURQUOI le pot ne suffit pas ? V9.24 CORRIGÉE
  • Pot alimenté par +12V_PROT (~11,7V) — PAS +5V comme indiqué en V9.23
  • PWM_IN max via pot = ~11,7V
  • Après diviseur : ADC_DIV max = 11,7V × 0,377 = 4,41V
  • ADC max = 4,41V / 5V × 1023 = ~902 counts
  • 902 < 950 → Impossible d'atteindre ADC > 950 via pot seul !

🔧 Solution: Injection directe sur PWM_IN

Pour atteindre ADC > 950 :

  • ADC 950 → V_ADC_DIV = 950/1023 × 5V = 4,64V
  • V_PWM_IN requis = 4,64V / 0,377 = 12,3V
  • → Injecter 13-15V directement sur PWM_IN
  • ⚠️ Ne JAMAIS dépasser 15V (protection diodes internes ATtiny)
