🛑 RÈGLE ABSOLUE : PWM_IN ne doit JAMAIS flotter en l'air !

Toujours connecté au potentiomètre OU au générateur JDS6600.

Détail du câblage potentiomètre

Potentiomètre 10kΩ linéaire :

  • Pin 1 (une extrémité) → +12V_PROT
  • Pin 2 (curseur central) → PWM_IN du circuit
  • Pin 3 (autre extrémité) → GND

→ Rotation du potentiomètre = tension 0V à 12V sur PWM_IN

→ Position initiale : Curseur à fond vers GND = 0V

Charge de sortie (simulateur jauge Innovate)

Pourquoi 120Ω ?

La jauge Innovate MTX-L tire environ 100mA à 12V → R = 12V/0,1A = 120Ω

Cette résistance simule la charge réelle pour des tests représentatifs.

Puissance : P = 12²/120 = 1,2W → Utiliser 2W minimum

Phase 5.1 — Fail-safe diviseur 🔧

🔧 CORRIGÉ V9.14 — Seuils réels du firmware

Le code V1.7.7+ détecte si la lecture ADC est hors plage :

  • ADC < 50 → Défaut diviseur (R2 coupée ou court-circuit vers GND)
  • ADC > 950 → Défaut diviseur (R1 coupée ou court-circuit vers +5V)

⚠️ Correction V9.14 : Les seuils réels sont 50 et 950, PAS 0 et 1023.

En cas de défaillance détectée, la sortie passe en mode OFF (fail-safe).

📐 RAPPEL V9.16 — Formules de conversion ADC ↔ V_PWM
Diviseur résistif R1/R2 :
k = R2 / (R1 + R2) = 20kΩ / (33kΩ + 20kΩ) = 0,377

Conversion ADC → V_PWM :
V_ADC = ADC × (Vref / 1023) = ADC × (5V / 1023)
V_PWM = V_ADC / k = V_ADC / 0,377

Résolution : 1 count ADC ≈ 12,95 mV sur PWM_IN

Exemple SEUIL_BAS_ON (ADC 239) :
V_ADC = (239 / 1023) × 5V = 1,168V
V_PWM = 1,168V / 0,377 = 3,10V ✓

Compatibilité : Les seuils V1.7.8 sont identiques à V1.6.6. Le comportement de la fenêtre est inchangé.
